Atomic CRM demo dataset
Source: https://github.com/marmelab/atomic-crm/tree/8b5d47ba32190c68801a427ef7682d7a6afc14e0/src/components/atomic-crm/providers/fakerest/dataGenerator
Reused unchanged generator; faker 5.5.3, date-fns 3.6.0, seed 1150, UTC reference date 2026-10-11T12:00:00Z.
All 2,518 records retained. IDs/reference IDs prefixed donor-, configuration ID remains 1. Server/auth/derived fields omitted to fit House schema. Remote and embedded portraits/logos omitted for honest initials; no remote images are used. Carriage returns in generated paragraph strings are normalized away because the current House YAML subset does not accept \r escapes; paragraph newlines remain. Data resides in Room documents, not the App bundle.
